# nodos.kr

**모든 개인은 스스로 전기를 쉽게 생산할 수 있어야 한다.**
그리고 스스로 생산한 전기를 쉽게 사용할 수 있어야 하며, 쉽게 사고팔 수 있어야 한다.

> Everyone should be able to produce their own electricity easily,
> to use what they made easily, and to buy and sell it easily.

전기를 전공하지 않은 한 사람이 자기 손으로 전기 자립을 만들어 가는 기록입니다.
된 것, 안 된 것, 틀린 것을 그대로 남깁니다.

**https://nodos.kr**

---

## 만들려는 것

태양광 패널과 배터리를, 들고 다닐 때는 한 덩어리로, 쓸 때는 쉽게 나뉘도록 만든 휴대용 발전기.

2026년 8월에 방향을 한 번 바꿨습니다. 베란다 고정형에서 들고 다니는 쪽으로.
그 전 방향으로 만든 것들도 지우지 않고 사이트에 그대로 두었습니다.

## 이 저장소

빌드 없는 정적 사이트입니다. `index.html` 을 브라우저로 열면 그대로 돕니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 랜딩 (한국어) |
| `en/index.html` | 랜딩 (영어) |
| `balcony-viewer.js` | Three.js 3D 베란다 시뮬레이터. 난간 바깥과 창문 안쪽의 발전량 차이를 만져볼 수 있습니다 |
| `study/` | 전기를 하나도 모르는 자리에서 시작하는 공부 글 |
| `archive/` | 그전에 만든 판. 안 지웁니다 |

## 지켜야 할 것

**지어낸 사실을 페이지에 쓰지 않는다.**

없는 팀, 못 하는 서비스, 가짜 후기, 출처 없는 숫자를 넣지 않습니다.
숫자에는 그것이 계산값인지 관찰값인지 목표값인지 적습니다.
